# @soraui/icons

> Official iconography utilities and brand icons for SoraUI.

[![license](https://img.shields.io/npm/l/@soraui/core.svg)](https://github.com/adityadwi21/SoraUI/blob/main/LICENSE)

---

## Overview

`@soraui/icons` provides internal brand icon SVG assets and helpers used across the SoraUI documentation platform and templates.

For general component iconography, SoraUI standardizes universally on [`lucide-react`](https://lucide.dev).
