# @soraui/hooks

Lightweight, accessible React hooks for interactive UI components.

## Installation

```bash
npm install @soraui/hooks
# or
pnpm add @soraui/hooks
```

## Available Hooks

- `useEscapeKey`: Accessible keyboard escape handler.
- `useClickOutside`: Detect clicks outside target elements.
- `useFocusTrap`: Modal dialog focus containment.
- `usePositioning`: Zero-dependency floating element positioning with collision detection.
- `useControllableState`: Seamless support for both controlled and uncontrolled states.
- `useRovingFocus`: WAI-ARIA compliant roving tabindex for lists, menus, and tabs.
- `Portal`: Render floating content cleanly into `document.body`.
