# Textarea

Multi-line text input with custom resize control and error state.

## Import
```tsx
import { Textarea } from '@soraui/react';
```

## Usage
```tsx
<Textarea placeholder="Enter your feedback..." rows={4} />
<Textarea error="Feedback is required" />
```

## Props
- `error`: `string | boolean`
- `resize`: `'none' | 'vertical' | 'horizontal' | 'both'`
