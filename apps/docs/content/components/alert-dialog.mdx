# Alert Dialog

> Modal dialog yang menginterupsi alur pengguna untuk menampilkan konten penting dan meminta konfirmasi eksplisit sebelum tindakan dijalankan. Ideal untuk tindakan destruktif atau tidak dapat dibatalkan.

**Status:** stable  
**Package:** `@soraui/react`  
**Path sumber:** `packages/react/src/components/alert-dialog/alert-dialog.tsx`  
**Path style:** `packages/react/src/styles.css` (seksi `.sora-alert-dialog__*`)  
**Bundle impact:** ~1.2 KB gzip, dependensi internal `@soraui/hooks` (`useFocusTrap`, `useEscapeKey`, `Portal`)  

---

## Philosophy Note

> Berbeda dari `Dialog` biasa yang dapat ditutup dengan mengklik area backdrop di luar modal, `AlertDialog` **sengaja tidak dapat ditutup dengan klik luar** untuk mencegah pembatalan yang tidak disengaja saat aksi kritis sedang berlangsung.
> 
> - **Zero-Runtime CSS** — Semua animasi transisi (fade-in, scale-in) berjalan di level CSS GPU.
> - **Focus Safety** — Secara default fokus otomatis diarahkan ke tombol `AlertDialogCancel` untuk mencegah pengguna tidak sengaja menekan Enter pada tombol destruktif.
> - **WAI-ARIA Compliant** — Menggunakan `role="alertdialog"`, `aria-modal="true"`, `aria-labelledby`, dan `aria-describedby`.

## Usage (Basic)

```tsx
<AlertDialog>
  <AlertDialogTrigger asChild>
    <Button variant="destructive">Delete Account</Button>
  </AlertDialogTrigger>
  <AlertDialogContent>
    <AlertDialogHeader>
      <AlertDialogTitle>Are you absolutely sure?</AlertDialogTitle>
      <AlertDialogDescription>
        This action cannot be undone. This will permanently delete your account
        and remove your data from our servers.
      </AlertDialogDescription>
    </AlertDialogHeader>
    <AlertDialogFooter>
      <AlertDialogCancel>Cancel</AlertDialogCancel>
      <AlertDialogAction className="sora-alert-dialog__action--destructive">
        Yes, delete account
      </AlertDialogAction>
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>
```

## API Reference

### AlertDialog

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `open` | `boolean` | `undefined` | Controlled state pembukaan dialog. |
| `defaultOpen` | `boolean` | `false` | Uncontrolled state awal pembukaan dialog. |
| `onOpenChange` | `(open: boolean) => void` | `undefined` | Callback saat status pembukaan dialog berubah. |
| `children` | `ReactNode` | — | Elemen `AlertDialogTrigger` dan `AlertDialogContent`. |

### AlertDialogTrigger

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `asChild` | `boolean` | `false` | Jika `true`, meneruskan perilaku klik ke komponen anak langsung (misal `<Button />`). |

### AlertDialogContent

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `size` | `'default' \| 'sm'` | `'default'` | Ukuran lebar maksimal modal dialog. |
| `className` | `string` | — | Class CSS kustom tambahan. |

### AlertDialogAction & AlertDialogCancel

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `onClick` | `(e: MouseEvent) => void` | — | Handler event klik. Secara default langsung menutup modal setelah dieksekusi. |
| `className` | `string` | — | Class CSS tambahan (gunakan `.sora-alert-dialog__action--destructive` untuk tombol aksi merah). |

## Accessibility (a11y)

- **Role:** `role="alertdialog"` memberitahu screen reader bahwa modal memerlukan interaksi konfirmasi langsung.
- **Modal Lock:** `aria-modal="true"` mengisolasi fokus keyboard dan virtual cursor screen reader.
- **Accessible Name & Description:** Secara otomatis mengaitkan `aria-labelledby` ke `AlertDialogTitle` dan `aria-describedby` ke `AlertDialogDescription`.
- **Keyboard Navigation:**
  - `Escape`: Menutup alert dialog.
  - `Tab` / `Shift + Tab`: Menavigasikan fokus secara melingkar (*focus trap*) di dalam dialog.
  - `Enter` / `Space`: Menjalankan aksi tombol yang sedang berfokus.
- **Initial Focus Safety:** Fokus awal otomatis diarahkan ke `AlertDialogCancel` untuk mencegah kesalahan eksekusi pada tindakan destruktif.
