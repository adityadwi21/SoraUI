# Typography

Semantic typography component with heading, body, lead, code, and caption variants.

## Import
```tsx
import { Typography } from '@soraui/react';
```

## Usage
```tsx
<Typography variant="h1">Hero Title</Typography>
<Typography variant="body">Regular body copy paragraph.</Typography>
<Typography variant="code">const x = 10;</Typography>
```

## Props
- `variant`: `'h1' | 'h2' | 'h3' | 'h4' | 'h5' | 'h6' | 'body' | 'body-sm' | 'caption' | 'lead' | 'code'`
- `as`: polymorphic HTML element override (`'h1' | 'h2' | 'p' | 'span' | 'code' | ...`)
