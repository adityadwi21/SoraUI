# Input

Accessible text input field with error states and size variants.

## Import
```tsx
import { Input } from '@soraui/react';
```

## Usage
```tsx
<Input placeholder="Enter your email" />
<Input error="Invalid email address" />
<Input size="sm" placeholder="Compact input" />
```

## Props
- `size`: `'sm' | 'md' | 'lg'` (default: `'md'`)
- `error`: `string | boolean`
- `disabled`: `boolean`
