# Alert

> Displays a callout banner for user attention with support for status icons and destructive actions.

**Status:** stable
**Package:** `@soraui/react`
**Path:** `packages/react/src/components/alert/alert.tsx`
**Styles:** `packages/react/src/styles.css` (`.sora-alert*`)

---

## Installation

```bash
# Via CLI
npx @soraui/cli add alert

# Via NPM
npm install @soraui/react lucide-react
```

---

## Usage

```tsx showLineNumbers
import { Alert, AlertTitle, AlertDescription } from "@soraui/react";
import { Terminal, AlertCircle } from "lucide-react";

export function AlertDemo() {
  return (
    <Alert>
      <Terminal size={16} />
      <AlertTitle>Heads up!</AlertTitle>
      <AlertDescription>
        You can add components to your app using the cli.
      </AlertDescription>
    </Alert>
  );
}
```

## Variants

### Default

```tsx
<Alert>
  <Terminal size={16} />
  <AlertTitle>Heads up!</AlertTitle>
  <AlertDescription>
    You can add components to your app using the cli.
  </AlertDescription>
</Alert>
```

### Destructive

```tsx
<Alert variant="destructive">
  <AlertCircle size={16} />
  <AlertTitle>Error</AlertTitle>
  <AlertDescription>
    Your session has expired. Please log in again.
  </AlertDescription>
</Alert>
```
