# Card

Flexible container card with header, title, description, content, and footer.

## Import
```tsx
import { Card, CardHeader, CardTitle, CardDescription, CardContent, CardFooter } from '@soraui/react';
```

## Usage
```tsx
<Card>
  <CardHeader>
    <CardTitle>Analytics</CardTitle>
    <CardDescription>View your app traffic</CardDescription>
  </CardHeader>
  <CardContent>Content here</CardContent>
  <CardFooter><Button>Learn more</Button></CardFooter>
</Card>
```
