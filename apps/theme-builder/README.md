# @soraui/theme-builder

Interactive visual theme builder and WCAG 2.1 contrast evaluation engine for SoraUI.

## Features
- **9 Sky/Space Presets**: Sky, Cloud, Horizon, Aurora, Twilight, Midnight, Nebula, Eclipse, Starlight.
- **Real-Time WCAG 2.1 Contrast Engine**: Evaluates AA and AAA compliance on text and surface pairs.
- **Component Showcase**: Live preview of all Level 1, Level 2, and Level 3 SoraUI components.
- **Pure CSS Variable Exporter**: One-click copy or `.css` file export (zero JS runtime styling).

## Running Locally
```bash
pnpm --filter @soraui/theme-builder dev
```
